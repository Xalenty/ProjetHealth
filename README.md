## À propos

Ce projet consiste à concevoir et à développer une application mobile cross-platform avec le langage Dart et le SDK Flutter connecté à une API REST, en lien avec les thématiques de l'IoT, du Big Data et de l'E-Santé.

Elle s'adresse à deux types d'utilisateurs potentiels :
* **Professionnels de santé** (médecin, coach) : Suivi des patients, évolution physiologique/psychique, et communication.
* **Patients** : Suivi personnel (perte/gain de poids), activités physiques, et interactions avec le professionnel.
